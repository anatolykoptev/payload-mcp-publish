# Changelog

## 0.1.0 (2026-11-26)

First release: `mcpPublishLane` for Payload 3 with `@payloadcms/plugin-mcp` 3. `publishDraft` dry run with a full field diff and a content digest, publish only with the matching digest, the key's own update permission, an in-transaction pin against a save between review and publish, refusal of documents the owner unpublished, refusal of any other MCP publish path, optional publish gate.
